# 卓球プレー分析システム (Table Tennis Analytics)

卓球の1プレー（サーブから得失点まで）の要因・技術・コース・回転・ミス種別をスマホやタブレットからタップで記録し、相手の戦型・利き腕・期間・技術階層に応じたリアルタイム多角分析を行うWebアプリケーションです。

---

## 主な機能

### 1. 試合のメタデータ登録（1試合の最初）
- **日付**
- **ゲーム種類**: 公式大会 / 練習 / 非公式大会
- **大会名 / 対戦相手名**
- **相手の利き腕**: 右利き / 左利き
- **相手の戦型**: シェーク攻撃 / ペン攻撃 / カットマン / 粒高（攻撃寄り） / 粒高（守備寄り） / 表ソフト速攻 / その他
- **相手のラバー情報**: フォア面 ＆ バック面（裏ソフト / 表ソフト / 粒高 / アンチ）
- **ゲーム形式**: 3ゲーム制 / 5ゲーム制 / 7ゲーム制

### 2. 1プレー単位の記録（モバイル＆タブレット最適化）
- **得点 / 失点**
- **サーバー**: 自分 / 相手
- **直接係るプレー**:
  - **サーブ / サーブミス**: 長さ（ショート/ハーフロング/ロング） × コース（フォア/フォアミドル/バックミドル/バック） × 回転（下/横下/横上/逆横下/逆横/ナックル/上/不明）※卓球台ビジュアルUI対応
  - **レシーブ / レシーブミス**: 技術（ツッツキ/ストップ/流し/フリック/チキータ/ドライブ/軽打/浮き球） × 送球コース
  - **３球目攻撃 / ３球目攻撃ミス**: 打法（フォア/バック） × レシーブコース × 3球目狙いコース × 種類（ループドライブ/ドライブ/スマッシュ/角度打ち）
  - **ラリー**: 台上 / つなぎ / ブロック / 攻撃 / しのぎ / チャンスボール
- **ミス種別**: ネット / オーバー / ノータッチ / 空振り・振り遅れ / 相手エッジ / 相手ネットイン / その他
- **スコア自動連動 ＆ 1手戻す（Undo）**

### 3. 多角分析ダッシュボード
- **柔軟な条件絞り込み**:
  - 期間、対象試合、ゲーム種類
  - 相手戦型、相手利き腕
  - 技術大分類（サーブ全体、レシーブ全体、3球目全体、ラリー等）
  - 技術詳細（例: レシーブ「ツッツキ」、サーブ「ショート下回転」など）
  - ミス種別
- **リアルタイム集計**:
  - 対象プレー数、総合得点率（%）、失点率（%）
  - 自サーブ時得点率、レシーブ得点率、ミス発生率
- **ビジュアル可視化**:
  - **卓球台ヒートマップ**: サーブ配球や3球目攻撃コースの得点率と打球数を台上にオーバーレイ表示
  - **相手戦型別得点率グラフ**
  - **技術別得点率ランキング**
  - **ミス要因の内訳（円グラフ）**

### 4. データ管理・エクスポート
- **CSVエクスポート**: ExcelやGoogleスプレッドシートで分析可能（UTF-8 BOM付き）
- **JSONバックアップ ＆ 復元**: ワンクリックでバックアップとインポート
- **ローカル完結 ＆ Supabaseハイブリッド対応**: サーバー不要で即座に動作し、環境変数設定でクラウド同期も可能

## 開発環境の起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## GitHub & Vercel への公開手順

### 1. GitHubリポジトリへのプッシュ
```bash
git init
git add .
git commit -m "Initial commit of table tennis analytics system"
git branch -M main
git remote add origin <あなたのリポジトリURL>
git push -u origin main
```

### 2. Vercelへのデプロイ
1. [Vercel](https://vercel.com) にログインし、「Add New Project」から上記GitHubリポジトリをインポートします。
2. そのまま「Deploy」をクリックすれば数分で全世界に公開されます。

### 3. Supabaseとの連携（オプション）
1. [Supabase](https://supabase.com) で新規プロジェクトを作成します。
2. SQL Editor を開き、本プロジェクト内の `supabase/schema.sql` の内容を貼り付けて実行します。
3. Supabaseの Project Settings > API から `Project URL` と `anon public key` を取得します。
4. Vercelのプロジェクト設定（Environment Variables）に以下を登録します:
   - `NEXT_PUBLIC_SUPABASE_URL`: `https://your-project.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: `your-anon-key`
